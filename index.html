รอให้ LIFF พร้อม

หาก LINE แสดง “เพื่อน 0” ให้เพิ่มเพื่อนทดสอบในบัญชี LINE ก่อน ระบบจะไม่สร้างรายชื่อจำลอง

แก้ข้อความ Flex แบบง่าย ไม่ต้องเขียน JSON

แก้ชื่อแคมเปญ รายละเอียด และข้อความบนปุ่ม แล้วกดทดลองใช้ ระบบจำเฉพาะเบราว์เซอร์นี้ ยังไม่เผยแพร่ให้ลูกค้าทุกคน

แก้ได้โดยไม่ต้องแตะ JSON

เตรียม Flex JSON ใหม่

สำหรับเทมเพลตขั้นสูง: วาง Flex JSON เพื่อตรวจและทดลองแชร์ ส่วนข้อความทั่วไปใช้ช่องแก้แบบง่ายด้านบนได้
